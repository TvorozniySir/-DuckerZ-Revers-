# -DuckerZ-Revers-

Мой личный репозиторий с решениями CTF-задач, заметками и практикой в области обратной разработки (Reverse Engineering).

## 📌 О репозитории

Здесь я собираю разборы решённых задач, изучаю устройство исполняемых файлов, учусь читать ассемблер и исследую алгоритмы проверки данных.
Моя цель — постепенно развивать навыки анализа бинарных файлов и документировать процесс решения каждой задачи, от первого знакомства с программой до получения флага.

## 🧰 Инструменты

- **Cutter** — анализ исполняемых файлов, дизассемблирование и декомпиляция.
- **Python** — написание скриптов для автоматизации и восстановления данных.
- **GDB** 

## ⚠️ Примечание

Репозиторий создан в образовательных целях. Все решения предназначены для изучения методов анализа программ и развития практических навыков в CTF.
