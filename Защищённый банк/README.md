## Анализ

### 1. Изучение исполняемого файла

Для анализа предоставлен файл `protected_bank.exe` — исполняемый файл Windows x64.
Запускаем Cutter, открываем там файл, выполняем авто-анализ

### 2. Поиск строк

Первым шагом можно проверить, какие текстовые строки содержатся в бинарном файле. Для этого подходят утилиты `strings` и панель Strings в Cutter.
Во вкладке Strings было обнаружено 285 items, должно быть лень перебирать каждый из них своими глазками, поэтому используется поиск в этом же окне ("быстрый фильтр")
Написав DUCKERZ (так выглядит вводимый флаг на сайте), мы нашли такую строку: DUCKERZ{StR1ing3_s0lv3_th1s_B1NK}

## Результат

Флаг найден при статическом исследовании строк бинарного файла.
